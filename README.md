# 2C2P Agent Skills

A central repository of 2C2P resources that help AI assistants provide more consistent, context-aware support for product discovery, implementation, and development workflows.

## What this repository provides

This repository helps teams extend AI assistants with reusable 2C2P knowledge and guided capabilities.

- **Skills** — task-focused guidance that an AI assistant can use to help with specific 2C2P scenarios.
- **Steering** — shared context and instructions that keep AI responses aligned with 2C2P standards and documentation.
- **Powers** — packaged capabilities that combine guidance, tools, and supporting resources for broader workflows.
- **Plugins** — platform-specific integrations and configuration for making these resources available in supported AI development environments.

## Repository structure

| Path | Purpose |
| --- | --- |
| [`skills/`](./skills/) | Reusable AI agent skills and usage guidance. |
| [`steering/`](./steering/) | Shared instructions and reference material. |
| [`powers/`](./powers/) | Packaged capabilities and supporting resources. |
| [`plugins/`](./plugins/) | Agent plugins and related configuration. |

## Get started

1. Browse [`skills/`](./skills/) to find available guidance.
2. Read the [Skills guide](./skills/README.md) to understand how to use the available resources.
3. Explore [`steering/`](./steering/) and [`powers/`](./powers/) for additional context and capabilities.
4. Follow the documentation included with each resource.

## Contributing

# 2C2P Payments — VS Code Extension

Integrate 2C2P Payment Gateway with AI-assisted guidance — accept cards, wallets, QR payments across Southeast Asia.

## Features

- **@2c2p Chat Participant** — Ask payment integration questions in Copilot Chat
- **Tree View Sidebar** — Browse all integration methods (QuickPay, Hosted Payment Page, Direct API, etc.)
- **Documentation Panel** — Read formatted docs without leaving VS Code
- **Code Snippets** — Quick templates for JWT signing, payment tokens, webhooks
- **Credential Setup** — One command to configure sandbox credentials

## Usage

- Type `@2c2p` in Copilot Chat to ask questions
- Click the 2C2P icon in the Activity Bar to browse documentation
- Use `Cmd+Shift+P` → "2C2P: Setup Sandbox Credentials" to get started

## Supported Tech Stacks

Node.js, .NET, Python, PHP, Java

# 2C2P Merchant AI Integration Guide

## Purpose

This guide helps merchants use 2C2P Merchant AI Integration guidance with an AI assistant. Use it to explore questions in everyday language, then review the assistant's guidance before acting on it.

## Scope

This guide is for using Merchant AI Integration guidance in an AI assistant. It does not explain application-to-2C2P Payment API integration.

## Using the guidance with an AI assistant

Open the companion guide and share or reference the relevant guidance in an approved AI assistant. Describe your question in everyday language, ask follow-up questions when you need clarification, and review each response before acting on it.

## Companion guide

Open the companion guide at https://docs.google.com/document/d/1ghEQROTmT_aJpJsL_0qFQsHBRGavJtQlJh_ElPaSoQU/edit?tab=t.0#heading=h.arufix4ultt2. You must sign in to Google and may need access to open it.

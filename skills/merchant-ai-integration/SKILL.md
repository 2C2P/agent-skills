# 2C2P Merchant AI Integration

## Purpose

The 2C2P Merchant AI Integration skill helps merchants use an AI assistant with the right context for their 2C2P-related questions. It supports clear conversations, useful explanations, and reviewable guidance while merchants work through their tasks.

## Scope

This skill explains, in plain language, how to add and use the skill in an AI assistant. It does not teach payment API integration.

## Add the skill to an AI assistant

Get the current skill file from the 2C2P team, then open an approved AI tool and start a new chat session. Attach the skill file using the tool's Files or Attachment control. Ask the assistant to read the attached skill and help with your 2C2P-related task using the instructions it contains.

Describe the help you need in your own words. Continue the conversation with focused questions and ask the assistant to explain its recommendations before applying them.

## Use the skill in a conversation

Use the attached skill as context for the current session. You can ask the assistant to summarize guidance relevant to your task, identify information it needs to clarify the request, or break a request into reviewable steps and explain its recommendation before proposing changes.

The assistant may ask questions to understand your task. Review its response before acting on it. If the tool cannot attach a file, use an approved AI tool with a Files or Attachment option. If the assistant does not acknowledge the skill, start a new session, reattach the file, and ask it to read the skill again. For further help, contact [onboarding@2c2p.com](mailto:onboarding@2c2p.com).
